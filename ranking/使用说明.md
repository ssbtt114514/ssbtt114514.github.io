# 成绩排名系统 · 使用说明

液态玻璃 + Material Design 风格的成绩排名看板，支持多次考试独立查看、汇总平均排名，以及每位学生的详细成绩与历史走势。

## 一、目录结构

```
成绩排名系统/
├── 成绩排名系统.html      # 入口页面，双击或用浏览器打开
├── css/style.css          # 样式
├── js/                    # 功能模块（csv 解析 / 数据仓库 / 图表 / 主程序）
├── list/                  # 成绩数据目录
│   └── 2026-9-30/
│       └── main.csv       # 该次考试成绩
└── 使用说明.md
```

## 二、两种使用模式

### 模式 1：自动读取（推荐，需要本地服务器）

把每次考试的表格按 `list/日期/main.csv` 放好，例如：

```
list/2026-3-5/main.csv
list/2026-4-20/main.csv
list/2026-9-30/main.csv
```

然后在本目录启动一个本地服务器：

```bash
python3 -m http.server 8000
```

浏览器访问 `http://localhost:8000/成绩排名系统.html`，页面会自动扫描 `list/` 下的全部考试文件夹。

> 说明：直接双击 HTML（file 协议）时，浏览器安全策略禁止网页读取本地文件，自动读取不可用——此时请使用模式 2。
> 也可以编写 `list/manifest.json` 显式指定考试：`{"exams":["2026-3-5","2026-9-30"]}`。

### 模式 2：手动导入（任何环境都可用）

点击页面右下角的 `+` 按钮：

- **导入 CSV 表格**：一次可选多个 `.csv` 文件；
- **导入文件夹**：选择整个 `list` 文件夹，自动按子文件夹命名每次考试。

file 协议下导入的考试会保存在本机浏览器中，下次打开仍在（可在「管理考试」中删除）。

## 三、功能说明

- **总排名**：按总分排序；各科排名按该科分数排序，同分并列。
- **科目自动识别**：支持语文、数学、英语、物理、化学、地理、生物、历史、政治；表格里没有的科目自动隐藏。
- **汇总（平均）**：两次及以上考试时出现，按各次考试的平均分排名。
- **学生详情**：点击任意学生进入，包含：
  - 各科分数、班内排名、原表年名；
  - 历史走势折线图（总分 / 各科目 / 年名可切换）；
  - 最近一次考试的能力画像雷达图（相对该科最高分的百分比）；
  - 历次成绩明细表。
- **搜索**：按姓名快速筛选。
- **管理考试**：右上角图标进入，可重命名（按名称中的日期自动排序）或删除考试。

## 四、CSV 表格格式要求

首行为表头，至少包含「姓名」列和若干科目列；常见列名均可识别：

| 内容 | 支持的表头写法 |
| --- | --- |
| 姓名 | 姓名、名字、学生 |
| 总分 | 总分、总得分、合计（缺省时自动按各科求和） |
| 班级排名 | 班名、班级排名、班内排名 |
| 年级排名 | 年名、年级排名、校排名 |
| 科目 | 语文、数学、英语、物理、化学、地理、生物、历史、政治 |
| 科目排名 | 语文年名、数学年名……（缺省不影响使用） |

编码请使用 UTF-8。

## 五、单 HTML 版本

另有独立的 `成绩排名看板.html` 单文件版本：所有样式与脚本内联，支持手动导入表格/文件夹，但不支持自动读取 `list/` 目录，适合直接转发给他人使用。
