第一章：管理员职责与基础认知

1.1 你的角色定位

作为学生管理员，你是班级希沃设备的"第一守护者"。不需要懂编程，不需要会修硬件，只需要掌握以下几个核心操作，就能确保设备正常运行。

1.2 安全操作红线（必须遵守）

禁止行为 正确做法 严重后果
直接拔电源关机 点击开始菜单 → 电源 → 关机 系统损坏、数据丢失
开机状态下擦拭屏幕 关机并拔掉电源后再擦 触电风险、设备损坏
在冻结状态下安装软件 先解冻 → 安装 → 再冻结 软件重启后消失
软件没响应时连续猛点 耐心等待，或重启解决 打开数个窗口导致严重卡顿

第二章：核心密码与系统管理

2.1 希沃管家密码

默认密码： 000000（六个零）

用途说明：开启/关闭冰点还原（硬盘冻结）、查看设备状态与硬件信息。

注意：希沃管家已关联学校，无需再次操作。如果六个零提示错误，说明学校管理员已修改密码，请联系班主任或信息技术老师获取新密码。

2.2 冰点还原（硬盘冻结）详解

什么是冰点还原？ 想象硬盘是一块"记忆橡皮泥"：

  • 冻结状态：不管你怎么捏（安装软件、保存文件、改设置），重启后都会变回原来的样子
  • 解冻状态：捏成的新形状会被保留下来

重要例外：下载文件夹特殊说明
即使处于冻结状态，下载文件夹（Downloads）内的文件也不会被还原。方便临时存放文件。但重要文件仍建议在解冻状态下操作。

操作铁律：安装软件前 → 检查是否冻结 → 若冻结则解冻 → 安装完成后 → 重新冻结

解冻/冻结操作步骤：

  1. 在桌面找到"希沃管家"图标，双击打开。
  2. 输入密码：000000（或学校修改后的密码）。
  3. 在主界面找到"冰点还原"选项。
  4. 选择"解冻"或"冻结"。
  5. 根据提示重启电脑生效。

第三章：希沃白板5更新指南

  1. 打开希沃白板5软件。
  2. 点击界面左上角三条横线（≡）。
  3. 在弹出菜单中选择"关于我们"。
  4. 系统会自动检测版本 → 如有新版本，点击"立即下载"。
  5. 下载完成后，双击下载的 .exe 文件进行安装（覆盖安装）。
小贴士：更新前建议先解冻系统（见第二章），否则更新可能在重启后被还原。

第四章：日常维护操作

4.1 正确开关机

开机：按主机或屏幕上的电源按钮。

关机：点击屏幕左下角"开始" → "电源" → "关机" → 等待屏幕完全变黑。

严禁直接拔掉电源或长按电源键强制关机！

4.2 屏幕清洁规范

  • 时机：放学后或关机状态下。
  • 工具：湿润抹布（拧到不滴水）。

操作：关机并拔掉电源线 → 用湿润抹布擦拭屏幕，重点清洁四周边框的红外线触摸条 → 等待完全干燥再开机。

绝对禁止使用酒精、消毒液、纸巾或未关机擦拭。

4.3 触摸屏使用方法

  • 书写与擦除：优先使用触控笔。手掌不要大面积贴住屏幕，避免误触橡皮擦。
  • 故障排查：
    • 点击位置偏移：清洁四周边框红外线触摸条。
    • 触摸无反应：检查是否有物体遮挡边框 → 重启电脑。

第五章：预装软件使用指南

重要提示：由于本机运行内存仅4GB，电脑开机后，第一次启动希沃白板5会比较慢。请只双击一次，然后耐心等待，不要连续多次点击。
  • MusicFree（音乐播放器）：无广告，已配置插件，可直接搜索播放教学音乐。仅供教学使用。
  • Wallpaper Engine（动态壁纸）：不建议使用。会导致系统卡顿。
  • 夸克浏览器：内置AI助手、搜题、试卷去手写功能。仅在老师需要时使用。
  • 智慧中小学：从开始菜单中打开，桌面上没有快捷方式。

第六章：故障处理与求助

问题现象 解决方法
希沃白板第一次启动慢 耐心等待，不要连续点击（内存小）。
安装的软件重启后消失 解冻状态下重装 → 重新冻结（见第二章）。
触摸没反应/误触偏移 关机拔电源，用湿抹布清洁四周边框。
喇叭没声音 检查音量静音状态 → 右键音量图标选择正确播放设备。
希沃白板打不开 尝试重启电脑 → 如仍不行，联系老师。
