# 俄罗斯方块 Plus
经典俄罗斯方块的高维进化：一维→二维→三维→颜色系统→流体系统，随累计分数（0/100/800/10000/50000）自动解锁，叠加道具、方块属性与随机事件。

## 安装与运行
```bash
npm install
npm run dev      # 打开 http://localhost:5173
npm run build    # 产物输出 dist/（可离线双击 index.html）
npm test         # 运行全部单元/集成测试（Vitest）
```
固定 RNG 种子：`http://localhost:5173/?seed=12345`

## 玩法与目标
- 阶段一(0分)：6×12 一维线段，整列消除 +20
- 阶段二(100)：10×20 经典，满行 +50/行
- 阶段三(800)：10×10×20 三维，整排/列 +100，整层 +500
- 阶段四(10000)：6 色系统——满列/层且颜色≤4 种 +500；构成 2 阶及以上标准魔方（6 面异色，可空心）消除其全部 z 层，每层 +500
- 阶段五(50000)：流体系统——岩浆/水流动（元胞自动机），接触凝结；计分与普通方块一致
- 堆叠超过顶部红线即败

## 键位表
| 按键 | 功能 |
|---|---|
| ← / → | 横向移动 |
| ↑ / ↓ | 3D：深度移动；2D/1D：↓=软降 |
| Q / E | 旋转（2D 平面内 / 3D 绕 z 轴） |
| R / F，T / G | 3D 绕 x 轴 / 绕 y 轴 |
| Space | 硬降 |
| Shift | 3D 软降；组合键见道具 |
| 1 | TNT（目标点切比雪夫距离≤2 全毁） |
| 2 | 十字 TNT（6 面相邻） |
| 3 | 一字 TNT（整排至壁）；+Shift=Y 轴，+Alt=Z 轴 |
| 4 | 海绵（吸指定层全部水） |
| 5 | 排水桶（回收一格岩浆/水） |
| 6 | 墙壁炸弹（3×3×3）；+Shift=5×5×5 |
| Esc | 暂停/菜单（难/极难仅呼出菜单，游戏继续） |
| 鼠标 | 拖拽旋转 3D 视角；滚轮缩放；**悬停=道具瞄准**（黄框） |

## 道具与事件
道具在每次消除后按难度掉率掷骰入库（简单40%/正常30%/较难30%/难20%/极难0%）。事件（反重力/炸弹雨/雨天/塌方）按权重随机触发，全屏横幅提示。

## 自定义模式
主菜单 → 自定义模式：场地 5×5×5~100×100×50、维度、速度、属性概率、事件权重全部可调，支持 JSON 导出/导入（示例见 `configs/`）。

## 存档
暂停菜单“存档”→ localStorage 单槽位；主菜单“读档”无缝续玩。

## 目录结构
逻辑层 `src/core/`（纯函数，可单测）；渲染层 `src/render/`（Three.js）；UI `src/ui.ts`；全部可调数值在 `src/config.ts`。
