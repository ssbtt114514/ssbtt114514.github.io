# 高中生物

## 组成细胞的分子

### 核酸
- DNA
  - 脱氧核糖核酸
  - 脱氧核苷酸
  - A、T、G、C
  - 一般为双链
- RNA
  - 核糖核酸
  - 核糖核苷酸
  - A、U、G、C
  - 一般为单链
- 互补配对
  - DNA：A-T、G-C
  - RNA：A-U、G-C
- 遗传信息与核苷酸排列顺序有关

### 糖类
- 单糖
  - 葡萄糖：重要能源物质
  - 核糖：RNA组成成分
  - 脱氧核糖：DNA组成成分
- 二糖
  - 麦芽糖
  - 蔗糖
  - 乳糖
- 多糖
  - 淀粉：植物储能
  - 糖原：动物储能
  - 纤维素：植物细胞壁

### 脂质
- 脂肪
  - 储能
  - 保温
  - 保护
- 磷脂
  - 细胞膜的重要组成成分
- 固醇
  - 胆固醇
  - 性激素
  - 维生素D
